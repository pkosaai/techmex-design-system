Design System

Every element of techmexaustin.org, live and copy-ready. Take css/techmex.css and js/techmex.js (plus the logos in images/) to any HTML platform, then copy any component's markup below (View code) and it works as-is. No frameworks, no build step. The styleguide.* files are this page's chrome only.

What changed in v2.0: the palette moves from a mint-neon primary to a blue → teal → green spectrum derived directly from the logo's own gradient — technological and dimensional, not generic-startup neon. Typography now complements the logo's futuristic letterforms instead of competing with them: bold/black weights are reserved for one hero headline per page, section headings step down to 700/600, and Space Grotesk (the "signal" typeface) drops from 700 to 500–600 wherever it's UI voice — closer to a contemporary tech publication than cyberpunk or generic startup. See Color and Type families below for the full before/after.
Package layout: index.html · css/techmex.css (portable system) · css/styleguide.css (page chrome) · js/techmex.js (counters + countdown) · js/styleguide.js (snippet viewer) · images/ (logo files). Hexagons additionally need the hidden <svg><defs> block (top of this page's <body>) once per page.
01 · Branding — Logo

The logo

Three official lockups, all built from the same gradient wordmark (green → cyan → blue, the brand's signature direction) with the circuit-node hex mark. Always the original SVG files — never rebuilt in HTML text, never recolored, outlined, shadowed, rotated, or stretched. Dark backgrounds only.

02 · Branding — Color

    
Color

    
Blue → cyan → green, derived directly from the logo's own gradient — technological and dimensional, on a near-black canvas. Dark is the canvas (~62%), color is accent (≤8%). All tokens are CSS custom properties on :root — see css/techmex.css.

    
Changed in v2.0: the mint-neon Primary Green (#23F7B2, "generic startup") is retired — the logo-accurate #32B44A (v1.1's --tmx-logo-green) is promoted to Primary Green. Cyan (#00C8C8) and Teal (#00BFAE) are now two DISTINCT tokens, not one — Cyan is the bridge color in the brand gradient, Teal is a separate connection/transition accent. Dark and Surface both darken slightly (#080A0A / #161A1B) for more contrast headroom. A new Electric Green accent (#18B600) covers the rare case that still wants a bright, saturated flash — hover glows, success states — used sparingly, never as a fill. Variable NAMES are unchanged except for the new --tmx-teal, so any page already built on v1.1 tokens picks up this palette automatically.

    
Core 8 — exact match to the approved reference palette:

    

      
TechMex Blue--tmx-blue · #0063FFPrimary technology / action. Large text/icons only (4.0:1)

      
TechMex Cyan--tmx-cyan · #00C8C8Bridge color — gradients, hovers, links. AA 9.5:1

      
TechMex Teal--tmx-teal · #00BFAEConnection / transition accent. AA 8.1:1

      
TechMex Green--tmx-green · #32B44ACore logo green — accents, CTAs, highlights. AA 7.3:1

      
Electric Green--tmx-electric · #18B600Sparing accent: hover glow, success flash. Never a fill.

      
Silver--tmx-muted · #8C8C8CLogo / secondary, secondary text. AA 5.9:1

      
Dark--tmx-dark · #080A0ACanvas — base background

      
Surface--tmx-gray · #161A1BCards / surfaces

    

    
Extended tokens (decorative / accessibility — not part of the core 8, kept from v1.1):

    

      
Logo Blue--tmx-logo-blue · #4068B1Gradient end, decorative (3.6:1)

      
Accessible Blue--tmx-blue-a11y · #82ABFFSmall blue links (AA)

      
Success--tmx-success · #13BF00Success states. AA 8.0:1

      
Recommended brand gradient--tmx-grad · #0063FF → #00C8C8 → #32B44AWordmarks, short headlines — matches the reference palette exactly

      
UI gradient--tmx-grad-uiHex borders, UI strokes

    

    
Accessibility (WCAG 2.1 AA on #080A0A): body text never below rgba(255,255,255,0.6) (7.3:1). #0063FF and #4068B1 fail at normal size — use them for large/bold text and icons only; small blue links use --tmx-blue-a11y.
